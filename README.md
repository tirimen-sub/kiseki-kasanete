# キセキ・カサネテ

高校から大学までの移動ログを、日本地図の上に光の軌跡として重ねて再生するサイトです。

- 時間の流れに沿って軌跡が伸び、訪れた都道府県が塗られていきます
- 高校・大学1年・大学2年・大学3年の時期ごとに色分けし、表示を切り替えられます
- 総移動距離と到達都道府県数をリアルタイムで表示します
- 時期ごとの移動距離と、大学に入ってからの旅行の記録をリザルト画面で見られます
- フォロー / フリービューのカメラ、再生速度の変更、ライト / ダークテーマに対応しています

Three.js で描画し、GitHub Pages で公開しています。

## 出典

地図データ: 地球地図日本 (国土地理院) — [dataofjapan/land](https://github.com/dataofjapan/land) の `japan.geojson` を加工して使用

フィリピンの地図データ: [Natural Earth](https://www.naturalearthdata.com/)
